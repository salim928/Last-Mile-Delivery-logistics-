## Usage

The landing page is now the default home page at `/`. It automatically redirects authenticated users to `/dashboard`.

### Theme Toggle
Users can switch between dark and light themes using the toggle in the navigation bar. Theme state is managed with React useState (can be upgraded to localStorage for persistence).

### Navigation
All internal links use Next.js `<Link>` for client-side navigation. External links (email, phone) use standard anchor tags.
