🚚 Last-Mile Logistics Optimizer
Feature & Specification Roadmap (Phased)
🔹 PHASE 1 — SOLID MVP (NON-NEGOTIABLE)

Timeline: 2–3 weeks
Goal:

Prove merchants will pay because you save them money and time
This is what you use to win pilots, grants, angels, accelerators.

🎯 MVP Target Users

E-commerce merchants

Pharmacies

Supermarkets

SMEs using motorbikes / vans

Small courier companies

✅ MVP FEATURES (BUILD ONLY THESE)
1️⃣ Merchant Onboarding & Order Input

Why: Zero-friction onboarding = faster pilots

Features

CSV upload (orders, addresses, COD flag, delivery window)

Manual order entry (fallback)

Simple merchant profile (business type, city)

Spec

Accept 20–500 orders/day

Address normalization (basic)

No integrations yet (manual first)

2️⃣ Route Optimization Engine (CORE VALUE)

Why: This is what saves money → this is what sells

Features

Multi-stop route optimization

Support motorbike + van

Output:

Optimized stop order

Estimated distance

Estimated delivery time

Spec

Batch routing (daily planning)

Constraint-aware:

Delivery time windows

Vehicle type

No real-time traffic yet (keep simple)

3️⃣ Dispatcher / Operations Dashboard

Why: Businesses think in operations, not algorithms

Features

View all routes for the day

Assign rider to route (manual)

Status tracking:

Assigned

In transit

Delivered

Failed

Spec

Web dashboard (mobile responsive)

One-click reassignment

Export routes to PDF / CSV

4️⃣ Proof of Delivery (POD)

Why: Failed deliveries & disputes are a major pain

Features

Photo proof

OTP confirmation

Timestamp + GPS capture

Spec

Rider uploads via simple web/PWA

Offline capture → sync later

Attach POD to order record

5️⃣ Cash-On-Delivery (COD) Reconciliation

Why: THIS is where Ghanaian merchants lose money

Features

Expected COD vs collected

Daily COD summary

Flag mismatches automatically

Spec

Manual input for cash collected

Export reconciliation report

No payments processing yet

6️⃣ Customer ETA Notifications

Why: Reduces failed deliveries drastically

Features

SMS or WhatsApp ETA message

“Your rider is on the way” alert

Spec

One-way notifications only

Local phone number support

7️⃣ ROI / SAVINGS REPORT (THE SALES WEAPON)

Why: This is what convinces users AND investors

Features

Distance saved (%)

Time saved (%)

Estimated fuel cost saved

Failed delivery reduction

Spec

Compare optimized route vs naive route

Auto-generated 1-page report (PDF)

Branded for pitching to management

💰 MVP PRICING TEST

Pilot pricing:

Goal: at least 1 paying merchant

✅ MVP SUCCESS CRITERIA (VERY IMPORTANT)

👉 If this works, you do NOT pivot
